# Mock Data Inventory & Replacement Roadmap — Student OS

This document tracks all hardcoded/mock data currently in `frontend/src/data/mockData.ts`, marking their purpose, current status, and the development phase in which each will be replaced by real database persistence and API endpoints.

---

| Data Entity | Variable Name | Purpose in UI | Replacement Phase & API Endpoint |
|---|---|---|---|
| **User Profile** | `initialUser` | Mock student profile for Muthubalamurugan (RIT Chennai) | **Phase 2 (Auth):** Replaced by real authentication via `POST /api/auth/login` and `GET /api/me`. |
| **Subjects List** | `initialSubjects` | 6 engineering subjects with progress % and topic counts | **Phase 3 (Academic Core):** Replaced by SQLAlchemy `subjects` table via `GET /api/subjects` and `POST /api/subjects`. |
| **Tasks List** | `initialTasks` | 5 student assignment tasks with priorities and due dates | **Phase 3 (Academic Core):** Replaced by `tasks` table via `GET /api/tasks`, `POST /api/tasks`, and `PATCH /api/tasks/{id}`. |
| **Schedule Items** | `initialSchedule` | 5 daily timeline items on Dashboard | **Phase 7 (Today Screen):** Dynamically generated by the intelligence engine planner (`GET /api/today`). |
| **Topics & Reviews** | `initialTopicsDS` | Data Structures Unit 1-4 topics with stability and ratings | **Phase 6 (Learning Loop):** Replaced by `topics` & `topic_reviews` tables with dynamic recalculation via `POST /api/topics/{id}/review`. |
| **Calendar Events** | `initialCalendarEvents` | October 2026 study blocks | **Prototype only:** Screen moved to `frontend/src/prototype/` (out of MVP scope per Section 1). |
| **Career Paths** | `initialCareerPaths` | Career skill match recommendations | **Prototype only:** Screen moved to `frontend/src/prototype/` (out of MVP scope per Section 1). |

---

### Strict MVP Boundaries (Section 1)
All screens relating to `initialCalendarEvents` and `initialCareerPaths` reside in `frontend/src/prototype/` and are not part of the production MVP build.
